参数: R1 = 1.6 (顶面到法线交点O距离), R2 = 1.5 (底面到O距离),
      alpha = 20.0 deg (环块轴线倾角), 缝隙 g = 0.03 (相邻侧面垂直间距)
      块高 H = R1 - R2 = 0.05
      [侧面凸台] 凸台 = 侧面中央向外凸出的矩形块, 相邻块各凸 g/2 → 拼接时端面贴合接触;

坐标系约定
  [基座坐标系] = len_center 块自身的局部(STL)坐标系 (装配表参考系)
                  原点 = 中心块近O底面中心; x/y/z = len_center 的 STL 轴;
                  z 指向法线交点 O; len_center 在该系 xyz=rpy=0, q=(1,0,0,0);
                  法线交点 O 位于基座系 (0, 0, +R2)。
  [块局部坐标系] (即各块 STL 坐标系)
                  原点 = 该块近O底面(较小面)正中心; z 轴 = 该块轴线, 指向 O;
                  近O底面位于局部 z = 0 平面, 外表面(远O面)位于局部 z = -H 平面;
                  x 轴: 中心块 +x = 世界 +x; 其余块 +x 指向中心镜片(⊥ z 的径向内向);
                  每块局部系与基座系的关系见第二节装配表 (同一 STL 内容)。
  [侧面编号 S0..S5]
                  面朝该侧面外侧、沿镜片自身 +x 站立、俯视看向镜片自身 -z 方向时,
                  x 向右、y 向上, S0 起顺时针(ψ 递减)依次为 S1..S5。S0 的选取:
                    len_center : +x 方向的那个侧面;
                    len_ring1  : 与中心镜片对接的那个侧面;
                    len_ring2* : 自 +x 起顺时针数第一个与上一层(ring1)对接的侧面。
  [装配公式]      p_base = tB + M(qB) * p_local,  M = Rz(yaw)Ry(pitch)Rx(roll)
                  p_local 即 STL 文件中的顶点坐标;
                  URDF rpy 角度单位 = 弧度(rad), 用 <origin xyz=... rpy=.../> 直接填入。
  [几何不变性]    装配表改以 len_center 为基座后, 各块世界摆放与几何完全不变;
                  只是参考系换成 len_center 的 STL 系(中心块), z 朝外/朝上。

三、备注
------------------------------------------------------------------------------
1. 各块轮廓中心的法线(即块轴线, 局部 z 轴)在基座/世界系中全部交于点 O;
   O 在 len_center 基座系中的位置 = (0, 0, +R2) = (0, 0, 1.5)
2. 相邻块侧面为严格平行平面, 垂直间距恒为 g; 启用凸台后, 两侧面各向外凸 g/2,
   凸台端面恰在中分面贴合接触(本文件自检 42 对全部贴合)。
3. 顶/底面为近似正六边形(中心块严格正), 各边长微小差异见上表;
   底面边长 ≈ 顶面边长 * (R2/R1) + 缝隙修正。
4. GAP = 0 时退化为无缝拼接版本; BULGE_ENABLE = False 时不生成凸台(纯台体+缝隙)。
5. 块局部系: 原点 = 近O底面中心, +z 沿块轴线指向 O, 近O底面 z=0, 外表面 z=-H;
   俯视(看向 -z)时所见的金色面即为近O底面, 符合右手系, 可直填 URDF。
6. 非中心块局部 +x 在垂直于 z 的面内指向中心镜片; 中心块 +x = 世界 +x。
   装配表以 len_center 的 STL 系为基座: 第1块 xyz=(0,0,0), rpy=(0,0,0),
   q=(1,0,0,0); 其余块 (tB/qB/rpyB) 相对该基座系给出, 可直接作 URDF 世界系。
7. rpy 遵循 URDF 固定轴约定 R = Rz(yaw)Ry(pitch)Rx(roll), 角度单位 rad;
   同一姿态的四元数与 rpy 等价可相互校验, 直填 <origin> 即可。
8. 侧面编号 S0..S5: 面朝该侧面外侧、沿镜片 +x 站立、俯视看向镜片 -z 方向时,
   S0 起顺时针依次为 S1..S5。S0 = 中心镜片 +x 面 / ring1 与中心对接面 /
   ring2 自 +x 起顺时针第一个与 ring1 对接的侧面。
   侧面报告中 pos = 该侧凸台外端面中心(侧面中心沿外法向再凸 g/2);
   rpy/q 的 z 轴 = 该凸台外法向(指向邻块/朝外), x 轴 = 沿六边形棱方向。
