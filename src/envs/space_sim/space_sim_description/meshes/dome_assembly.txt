坐标系约定
  [基座坐标系] = len_center 块自身的局部(STL)坐标系 (装配表参考系)
                  原点 = 中心块底面(近O面)中心; x/y/z = len_center 的 STL 轴,
                  z 指向法线交点 O; len_center 在该系 xyz=rpy=0, q=(1,0,0,0)。
  [块局部坐标系] (即各块 STL 坐标系, z 指向 O)
                  原点 = 该块底面(靠近O的面)正中心; z 轴 = 该块轴线(指向 O);
                  底面位于局部 z = 0 平面, 顶面位于局部 z = -H 平面;
                  每块局部系与基座系的关系见第二节装配表 (同一 STL 内容)。
  [装配公式]      p_base = tB + M(qB) * p_local,  M = Rz(yaw)Ry(pitch)Rx(roll)
                  p_local 即 STL 文件中的顶点坐标;
                  URDF rpy 角度单位 = 弧度(rad), 用 <origin xyz=... rpy=.../> 直接填入。
  [几何不变性]    装配表改以 len_center 为基座后, 各块世界摆放与几何完全不变;
                  只是参考系从“世界系(中心块 z 朝上)”换成“len_center 的 STL 系”。

三、备注
------------------------------------------------------------------------------
1. 各块顶面中心的法线(即块轴线, 局部 z 轴)在基座/世界系中全部交于点 O;
   O 在 len_center 基座系中的位置 = (0, 0, +R2) = (0, 0, 1.5)
2. 相邻块侧面为严格平行平面, 垂直间距恒为 g; 启用凸台后, 两侧面各向外凸 g/2,
   凸台端面恰在中分面贴合接触(本文件自检 42 对全部贴合)。
3. 顶/底面为近似正六边形(中心块严格正), 各边长微小差异见上表;
   底面边长 ≈ 顶面边长 * (R2/R1) + 缝隙修正。
4. GAP = 0 时退化为无缝拼接版本; BULGE_ENABLE = False 时不生成凸台(纯台体+缝隙)。
5. 块局部系已翻转(绕局部 x 转 180°): STL 中 z 轴指向 O, 顶面 z=-H;
   STL 侧面法向 z 分量为正(背离 O 朝外倾斜)是翻转后正确几何, 勿再翻转。
6. 装配表以 len_center 的 STL 系为基座: 第1块 xyz=(0,0,0), rpy=(0,0,0),
   q=(1,0,0,0); 其余 18 块 (tB/qB/rpyB) 相对该基座系给出, 可直接作 URDF 世界系。
7. rpy 遵循 URDF 固定轴约定 R = Rz(yaw)Ry(pitch)Rx(roll), 角度单位 rad;
   同一姿态的四元数与 rpy 等价可相互校验, 直填 <origin> 即可。
8. 侧面 S_k 报告的 pos = 该侧凸台外端面中心(侧面中心沿外法向再凸 g/2);
   rpy/q 的 z 轴 = 该凸台外法向(指向邻块/朝外)。
